# P1A-07 BTC Manifest Draft Evidence

`schemas/examples/btc-system.yaml` defines BTC Backend/Web, dependency ordering, port propagation, and readiness structure. It deliberately uses Web preferred port `32102`; StackPilot itself remains on `32100` and Vite development on `32101`, with no StackPilot service using 5173.

The draft uses process readiness for Backend only because the current BTC source has no available authenticated-safe health endpoint. It is not an approved Phase 1B production readiness contract.
