# P0-03 Verification Evidence

## Scope

P0-03 establishes domain identifier value types, UTC persistent timestamps, state enumerations, dependency satisfaction rules, process identity, classifiable validation errors, and an explicit DTO/persistence boundary in `internal/domain`.

Status: `verification`

The implementation and automated checks are complete. It is based on local `main` commit `b47ab22` and remains uncommitted; remote GitHub verification is also unavailable because Git cannot acquire credentials.

## Contract decisions

- Manifest `systemId` and `serviceId` use `^[a-z][a-z0-9-]{0,62}$`.
- Workspace, system instance, operation, and reserved incident identifiers use `ws_`, `si_`, `op_`, and `inc_` plus a canonical uppercase ULID.
- Event IDs are positive 64-bit SQLite sequences.
- Persistent timestamps are non-zero UTC values formatted with `time.RFC3339Nano`.
- Domain types contain no JSON, YAML, or SQL tags. API DTOs and persistence models must map explicitly.
- Stable HTTP error codes are not invented in this package; P0-04 maps `errors.Is/As` categories at the API boundary.
- Phase 2 enum values such as `compose`, `oneshot`, `completed`, and `analyze` are contract-compatible values only. They do not enable those capabilities; manifest capability gates remain mandatory.

The detailed design was corrected to align the workspace and instance prefixes with its existing API examples.

## Test coverage

- Manifest ID minimum/maximum length, casing, leading character, and invalid symbols.
- Correct/incorrect prefixes, canonical ULID alphabet, length, casing, and overflow-leading digit.
- Positive, zero, and negative Event IDs.
- UTC normalization from an offset time, nanosecond round-trip, zero time, malformed time, and non-UTC offset rejection.
- Every defined Operation, step, service, system, dependency, driver, and process-mode value plus unknown values.
- Operation terminal classification.
- Only `ready` satisfies a ready dependency; only `completed` satisfies a completed dependency; degraded/unknown do not release dependencies.
- Domain structures do not carry transport or persistence tags.

## Known limitations

- ULID generation belongs to the workspace/operation creation use cases in later work packages. P0-03 validates and types identifiers without hand-rolling a generator.
- State transition graphs are implemented with the orchestrator work, not by this enumeration-only baseline.
- Race testing is unavailable in the current CGO-disabled Windows environment; this package has no goroutines or mutable package state.
- GitHub `origin/main` cannot be verified until GitHub credentials or an authenticated CLI are available.
