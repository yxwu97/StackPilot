- Server startup initializes authentication before HTTP readiness and refuses missing or mismatched secure storage.

- The browser exchanged the fragment for a 15-minute HttpOnly, SameSite=Strict cookie; reload rotated the in-memory CSRF value and retained access.
- Token rotation uses the Version 9 pending-hash journal, atomically replaces DPAPI storage, revokes the prior hash, invalidates browser credentials, and recovers either side of the crash window.
