# P1D-05 Browser Security Evidence

- Session exchange and browser mutations require a structurally parsed exact loopback Origin; a matching attacker-controlled Host/Origin pair is rejected to close DNS-rebinding bypasses.
- Browser mutations require JSON Content-Type and the CSRF value bound to the authenticated session. Bearer CLI requests remain a separate path without cookie downgrade.
- All JSON responses use `Cache-Control: no-store`; tokens, cookies, bootstrap codes, Authorization, and CSRF values are absent from DTOs and server logs.
- Real Playwright verification observed fragment removal, session exchange 201, authenticated catalog reads 200, workspace registration 201, refresh-session 200, and an authenticated POST without CSRF rejected with 403 before body validation.
- Contract and middleware tests cover malicious Origin, DNS rebinding, missing/incorrect CSRF, bootstrap replay/expiry, session expiry/revocation, and bearer/session route access.
