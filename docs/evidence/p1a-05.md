# P1A-05 Query API Evidence

Implemented under `/api/v1`:

- `POST /workspaces`, `GET /workspaces`, `DELETE /workspaces/{workspaceId}`
- `GET /systems`, `GET /systems/{systemId}`
- `GET /services/{systemId}/{serviceId}`

OpenAPI, the runtime error registry, and the human-readable error table are contract-tested for exact code/status/detail alignment. Service DTOs expose only ID, driver, mode, required status, and definition digest; tests assert that arguments, environment values, and working directories are absent. Browser mutations require exact Origin and the custom CSRF header; full authenticated sessions remain Phase 1D scope.

Verified with `go test ./internal/api -count=1`.
