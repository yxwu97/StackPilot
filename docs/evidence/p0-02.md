## Behavioral boundaries

- The production server address is fixed to `127.0.0.1`; only its port can be overridden.
- Server timeouts are bounded and cancellation uses a 15-second graceful shutdown context.
- Only GET and HEAD are accepted by the Web handler.
- Existing embedded assets are immutable-cacheable; the SPA index is not cached.
- Requests containing a `..` path segment are rejected.
- Extensionless client routes use SPA fallback; missing file-like paths return 404.
- Vite uses strict development port 32101 and proxies `/api` to port 32100.

## Known limitations

- The repository has no initial commit. This prevents P0-01/P0-02 from reaching `done` under the phased-plan definition.
- The current Web handler intentionally has no API, health, readiness, version, authentication, or SSE routes. Those belong to later Phase 0/1 work packages.
- Vite reports upstream Rollup annotation warnings from `@vueuse/core`; the build succeeds and generated chunks are valid.
