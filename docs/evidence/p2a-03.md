# P2A-03 Secret Injection Evidence

Status date: 2026-08-18

- Manifest validation now accepts only an exact environment value of the form `${secret.<name>}`. Embedded concatenation, non-environment use, invalid names, NUL, CR/LF, non-UTF-8, and process values above 16 KiB are rejected.
- `ResolvedServiceSpec` persists the placeholder plus an environment-name-to-Secret-name reference map. The three launch paths (single service, system DAG, and service restart) resolve immediately before `Driver.Start`, record provider/version metadata, and clear temporary values after the Driver and log capture boundaries copy what they need.
- Migration `000011_service_secret_versions.sql` and its repository record only service instance, environment name, Secret key, provider, version, and UTC resolution time. Empty-database, v10 upgrade, idempotence, monotonic advance, rollback rejection, foreign-key, and forbidden-column tests cover the schema.
- The private Supervisor request marks only which environment names are Secret-backed. Supervisor stdout/stderr use anonymous pipes and exact-value streaming redaction before any raw spool write, including matches split across read boundaries. Log Manager applies a second per-capture exact-value pass before NDJSON persistence and SSE publication, and clears its byte copies when capture closes.
- Reconciliation reloads the safe resolved spec and compares current provider versions with the recorded instance projection before resuming log capture. Missing, invalid, and changed versions map to `SECRET_NOT_FOUND`, `SECRET_INVALID`, and `SECRET_VERSION_CONFLICT` without including values.
- `scripts/verify-p2a-03.ps1 -Candidate .\.local\bin\stackpilot-p2a03.exe` passed on isolated control port `32110`. A real DPAPI Secret version 1 was injected into a supervised Java Runner fixture. The child repeatedly printed the Secret; raw spool, durable NDJSON, SSE/CLI output, status, resolved spec, SQLite/WAL/SHM, protected files, and the complete data tree contained no plaintext. Observable logs contained `[REDACTED:secret]`.
- The Gate verified the persisted environment name `STACKPILOT_GATE_SECRET`, key `p2a-secret/gate-key`, provider `dpapi-file`, version 1, and the safe `${secret.gate-key}` resolved-spec reference. Both managed services stopped normally, control port `32110` closed, and the isolated processes, data/workspace roots, logs, and fixture port were removed.
- `scripts/check.ps1` passed Web tests 6/6, strict TypeScript checking, the production Web build, all Go tests, and `go vet ./...`. `go test -race ./cmd/stackpilot ./internal/... -count=1` passed on Windows with repository-local MinGW 16.1.0, including real Named Pipe, DPAPI, Supervisor, Process Driver, storage, and orchestration tests. Linux and Darwin amd64 `CGO_ENABLED=0 go build ./...`, `git diff --check`, and the exact `AGENTS.md`/`CLAUDE.md` SHA-256 match also passed.

P2A-03 is verified. The server advertises `phase2.secret`; oneshot/completed and Python venv remain capability-gated for subsequent Phase 2A work packages.
