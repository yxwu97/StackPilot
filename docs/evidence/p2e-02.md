# P2E-02 Evidence - Bounded Automatic Restart

Status date: 2026-08-19

Automatic restart is a persisted `service-restart` Operation. Exit-policy matching distinguishes `never`, `on-failure`, and `always`; attempts and next eligibility survive control-plane restart, a stable window resets the counter, and Operation creation failure releases the database claim.

The real-SQLite integration matrix passed five consecutive runs:

```powershell
go test ./internal/orchestrator -run 'TestReconciliationPersistsAutomaticRestartByExitPolicy|TestAutomaticRestartLimitCreatesIncident|TestAutomaticRestartReleasesClaimWhenOperationCreationFails' -count=5
```

The limit case created a critical Incident with trigger `RESTART_LIMIT_REACHED` and created no further automatic Operation.
