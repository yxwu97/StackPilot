# P1D-06 Audit Evidence

- Migration 9 adds immutable, cursor-ordered `audit_events` and the token-rotation recovery journal.
- Workspace register/unregister, manifest refresh, system start/stop/restart, service restart, Operation cancel, and token rotation pass through one audit boundary.
- Records include safe subject/client type, action, target identifier, `accepted/succeeded/failed/denied` result, traceId, operationId, error code, and UTC time.
- Request bodies, workspace paths supplied in bodies, headers, cookies, tokens, commands, and environments are not recorded or returned.
- `GET /api/v1/audit-events` provides a bounded monotonic cursor page. Tests verify successful and CSRF-denied browser records and safe query DTOs.
- HTTP 202 is recorded as `accepted`, not as final success; the correlated persisted Operation/domain events remain the asynchronous outcome source of truth.
