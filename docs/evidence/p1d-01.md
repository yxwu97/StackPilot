# P1D-01 Startup Recovery Evidence

Status: verified on Windows on 2026-08-18.

- Startup atomically fails queued/running/cancelling Operations with `CONTROL_PLANE_RESTARTED`, settles unfinished steps, writes events, and releases the database workspace lock. Repeated recovery is idempotent.
- Active runtime scanning verifies persisted Supervisor and process identities through the protected Named Pipe before reattachment. A missing runtime becomes `failed`; unprovable ownership becomes `unknown` and is never terminated.
- The process-created/database-attachment crash window is covered by strict reads of `supervisor.json` and `services/<serviceId>/identity.json`, followed by live identity comparison before database attachment.
- `last_reconciled_at` is recorded after service and aggregate reconciliation. Reconciliation events intentionally have no user Operation scope.
- Stale reserved port leases expire only after TTL and never while their Operation is queued/running/cancelling. Bound leases are released only after proven process exit and an available endpoint check.
