# P1A-04 Manifest Snapshot Evidence

- Defaulted JSON is deterministic and hashed with SHA-256.
- Normalized YAML, parsed JSON, system metadata, workspace state, and service definition digests are committed atomically.
- A valid refresh installs a new immutable digest and replaces service summaries in one transaction.
- Duplicate-key, missing-file, and system-ID-change refresh failures mark the workspace invalid while retaining its last valid digest and services.
- Duplicate canonical registration rolls back all tentative system/snapshot writes.

Verified against real `modernc.org/sqlite` databases in `internal/storage/workspace_repository_test.go`.
