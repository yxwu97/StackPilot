# P2D-05 Evidence - PMS DAG and D-07

Status date: 2026-08-18

D-07 is closed from real code and runtime evidence:

- Backend constructs its RAG client without a startup network call and degrades RAG requests independently.
- RAG startup and health depend on Qdrant, not Backend.
- Backend and RAG are therefore independent startup roots and may start in parallel.
- Web waits for both `backend: ready` and `rag: ready`; stop order is the reverse dependency order.

The authoritative `E:\PMSystem\.stackpilot\system.yaml` encodes this graph, dynamic ports, readiness, stop timeouts, and Secret references. `schemas/examples/pms-system.yaml` provides a non-secret contract example. `TestRealPMSManifest` loads and semantically validates the real manifest only when `STACKPILOT_PMS_WORKSPACE` is set and asserts the dependency and propagation invariants.

```text
STACKPILOT_PMS_WORKSPACE=E:\PMSystem go test ./internal/manifest ./schemas
ok stackpilot/internal/manifest
ok stackpilot/schemas
```
