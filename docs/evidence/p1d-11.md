# P1D-11 Security, Recovery, and Release Evidence

Status date: 2026-08-18

- Lifecycle API contract tests explicitly reject `command`, `arguments`, `workingDirectory`, and `environment` overrides and reject starts from unregistered workspaces. Existing manifest path-boundary, authentication, Origin, CSRF, JSON content-type, audit-redaction, and token-redaction tests remain in the full repository suite.
- `service install`, `service start`, and `service upgrade` now wait for both the authenticated local control Pipe and HTTP `/health/ready`. `service stop` pins the reported process handle before requesting shutdown and waits for that exact process to exit before reporting success.
- Immutable-version Supervisor takeover accepts a replacement control plane only when the account SID matches and the candidate is the marker-selected `versions/<sha256>/stackpilot.exe` under the same canonical installation root. The marker checksum, directory digest, executable digest, and strict marker schema must all agree. Non-installed executions still require the exact Supervisor executable path.
