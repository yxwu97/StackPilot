Status date: 2026-08-18

P2C-01 is complete. The inventory below was taken from the real `E:\AIWorkflowStudio` workspace. No value from `deploy/.env` or `agent-runtime/.env` was read or copied; only committed examples and configuration keys were inspected.

## Existing startup chain

The legacy `start-aiws.bat` delegates to `scripts/start-aiws.ps1`. That script starts the complete Compose project, waits for Keycloak, runs `configure-local-keycloak.ps1`, then launches Server, Web, and Agent Runtime as detached PowerShell children. StackPilot must replace this lifecycle and must not invoke either launcher.

| Layer | Existing implementation | Default endpoint | Readiness | StackPilot target |
| --- | --- | --- | --- | --- |
| Infrastructure | Compose services `postgres`, `keycloak`, `minio`, `clamav`, `qdrant`, `otel-collector` | host ports 15432, 18180, 19000, 19001, 13310, 16333, 16334, 14317, 14318, 18889 | Compose health exists only for PostgreSQL, Keycloak, and ClamAV | One managed Compose service group with explicit dynamic host mappings and reliable healthchecks for every managed container |
| Keycloak Configure | PowerShell plus `docker compose exec` and `kcadm.sh` | container-local Keycloak 18180 | exit code 0 plus a final claims assertion | Process oneshot using a fixed supported Runner; `completed` releases downstream services |
| Server | Maven `spring-boot:run`, Java 21 | 18080 | HTTP `/actuator/health/readiness` | Maven daemon with dynamic port and infrastructure/configure dependencies |
| Agent Runtime | workspace Python 3.12 venv, `run.py` | 18090 | HTTP `/health/ready` | Python venv daemon with dynamic port and Secret-backed internal token |
| Web | npm `vite` | 6173 | HTTP `/` | npm daemon with dynamic listen port, API proxy, OIDC authority, callback, logout, and origin propagation |

## Secret boundary

The following values must be represented only by StackPilot Secret references and injected in memory: PostgreSQL password, Keycloak bootstrap administrator password, MinIO root password, Server-to-Runtime internal token, Runtime event signing secret, and any Runtime credential reference payload. User-facing local sample credentials from the imported development realm are test data, but they must not be copied into StackPilot evidence, snapshots, logs, or DTOs.

Non-secret identity and routing values remain ordinary environment: database username/name, Keycloak administrator username, OIDC client ID, ports, URLs, origins, retention flags, file limits, and allowlists.

## Dependency graph

```text
infrastructure ready
  -> keycloak-configure completed
       -> server ready
       -> agent-runtime ready
            -> web ready
```

Server and Agent Runtime may start in parallel after the Configure task completes. Web waits for both so its API and application runtime dependencies are ready before the browser entry point is advertised. Ordinary system stop reverses this order and uses Compose `stop`, preserving named volumes.
