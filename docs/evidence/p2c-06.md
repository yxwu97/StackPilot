# P2C-06 Evidence - AIWS UI Extension

Status date: 2026-08-18

P2C-06 is verified with the embedded production Web build and a real running AIWS instance.

## Implementation

- Runtime status now projects safe `driver`, `mode`, and Compose container state fields. Compose inspection returns only service, state, health, and exit code; it does not expose commands, environment, mounts, labels, or Secret values.
- The Web service list shows process/Compose driver and daemon/oneshot mode. `completed` is rendered as `已完成` and counts with `ready` in the system's successful-service summary.
- The service drawer renders a Compose container table and retains the bounded, virtualized log view.
- A planned logical `web` port creates the loopback-only `打开 Web` entry.
- OpenAPI, CLI DTOs, Web TypeScript DTOs, API mapping, and contract tests were updated together.
