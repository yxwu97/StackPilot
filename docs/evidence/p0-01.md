## Scope

P0-01 establishes the Go module, buildable `cmd/stackpilot` entry point, injected build metadata, Vue 3/Vite/TypeScript frontend, locked frontend dependencies, and unified Windows development commands. Web embedding, HTTP endpoints, domain types, SQLite, Schema, CI, and process supervision are outside this work package.

Status: `verification`

The implementation and automated checks are complete. Git was subsequently initialized and bootstrap commit `b47ab22` was created on local `main`. The package remains in verification because GitHub credentials are unavailable and the commit's presence on `origin/main` cannot be confirmed.

## Known limitations

- Local `main` contains bootstrap commit `b47ab22`; GitHub `origin/main` could not be read because Git credential acquisition failed.
- The in-app browser runtime failed to initialize after a clean reset with `Cannot redefine property: process`. Browser screenshot and DOM verification were not completed; HTTP reachability and production compilation did pass.
- The frontend is served by Vite only. Embedding it in the Go binary and adding SPA fallback belong to P0-02.
- P0-01 has no API, SQLite, manifest, process, SSE, or real-system behavior; those tests are not applicable yet.
