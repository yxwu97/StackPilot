## Gate Flow

`scripts/verify-p2c-07.ps1` creates an isolated StackPilot data root and securely imports the required existing AIWS settings into current-user DPAPI Secrets. Values remain in-process, are never printed, and are not copied to evidence.

The Gate then:

1. Registers the real AIWS workspace and starts the five-service DAG.
2. Verifies six healthy Compose containers, completed Keycloak Configure, ready Server/Runtime/Web, thirteen ports, and four live endpoints.
3. Repeats start and requires every step to be an idempotent skip.
4. Terminates and recreates the StackPilot control plane, then requires recovery of the same system instance.
5. Stops the full system through a persisted Operation.
6. Removes only the isolated containers, network, test volumes, managed processes, logs, and data root.
