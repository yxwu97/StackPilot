# P1A-02 Safe YAML Loader Evidence

- Input is limited to 1 MiB and must be a regular file.
- YAML duplicate keys are rejected at every mapping depth before typed decoding.
- Unknown fields are rejected against the typed manifest boundary.
- Malformed and multi-document YAML are rejected with stable categories.
- The embedded Draft 2020-12 Schema validates normalized JSON before semantic validation.
- Error strings contain logical locations and field names, not manifest values or host paths.

Verified with `go test ./internal/manifest -count=1` and the examples under `schemas/examples`.
