# P2A-02 Secret CLI and API Evidence

Status date: 2026-08-18

- Added authenticated `PUT/GET/DELETE /api/v1/secrets/{systemId}/{secretName}`. There is no value-read route. Responses contain only `id`, system/name, provider, version, and UTC update time. OpenAPI, stable error registry, human error table, DTOs, and contract tests are synchronized.
- Browser mutations require exact loopback Origin, bound CSRF header, session authentication, and JSON content type. CLI uses the local Bearer token. Audit records contain actions `secret.set`/`secret.delete` and target `system/name`; request bodies and values are never captured.
- `stackpilot secret set|get-metadata|delete [flags] <system> <name>` is implemented. `set` accepts exactly two identifiers and reads the value only from redirected stdin or a Windows console with echo disabled. A third plaintext positional argument, empty input, oversized input, unknown JSON fields, and invalid identifiers are rejected.
- API and CLI zero decoded/source buffers after use; the API client also clears its encoded request buffer. Metadata and error responses never include the value.
- `scripts/verify-p2a-02.ps1` passed against real candidate `0.2.0-p2a02` on isolated port `32108`. Two random stdin values produced versions 1 and 2, metadata reported `dpapi-file`, delete succeeded, and the next lookup returned `SECRET_NOT_FOUND`.
- The Gate stopped the verified control-plane PID before scanning every database, WAL/SHM, protected file, and server log under the isolated data root. Neither random value occurred. The control process, listener, logs, and Gate data root were removed afterward.
- API tests passed for metadata-only responses, CSRF denial, safe audit records, malformed/unknown fields, invalid keys, delete, and not-found mapping. CLI tests passed for CRLF stdin handling, empty/oversized rejection, and plaintext positional-argument rejection.
- The affected API/CLI/security/storage/entry packages passed Windows race testing. `scripts/check.ps1`, Linux/Darwin amd64 public-core builds, production-function length, `git diff --check`, and the exact `AGENTS.md`/`CLAUDE.md` hash match passed.

P2A-02 is verified. Manifest Secret references remain gated until P2A-03 completes pre-launch resolution, safe runtime snapshots, and redaction.
