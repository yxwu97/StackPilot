# P1B-08 Log REST and SSE Evidence

- `GET /api/v1/services/{systemId}/{serviceId}/logs` resolves the persisted SystemInstance/service pair to its internal ServiceInstance ID and verifies the requested system/workspace scope before reading logs.
- The historical contract returns the latest 500 entries by default, up to 5000, in ascending display order. `cursor` loads the newest older window; level/from/to filters are validated and applied by the Log Manager.
- The response DTO includes timestamp, public system/instance/service IDs, stream, level, redacted message, optional Operation ID, sequence, and truncation state. It never exposes ServiceInstance IDs, segment paths, spool paths, commands, environment values, or platform tokens.
- The existing forward `afterSequence` query remains unchanged for resumable streaming. The new `QueryWindow` path supplies latest/older UI windows without changing P1B-05 cursor semantics.
- The Log Broker receives entries only after redaction and successful segment writing. It retains a bounded 5000-entry per-ServiceInstance live ring and gives each SSE subscriber a bounded 256-entry channel.
- `/api/v1/log-stream` subscribes before historical catch-up, pages registered segments in bounded batches, merges and deduplicates the atomic Broker backlog by sequence, then streams `log.entry` SSE frames with sequence IDs and heartbeats.
- A full subscriber channel closes only that client; Broker publication and disk persistence never wait for the client. The last successfully written SSE `id` remains the reconnect cursor.
- Historical windows merge closed-segment results with the bounded active-segment ring, so current logs appear before `.active` rotation. If a reconnect cursor falls into a gap older than the ring and closed segments cannot fill it, the API returns `409 LOG_CURSOR_EXPIRED` instead of silently skipping entries.
- The real SQLite scope resolver and segment index are used in API tests with actual NDJSON files. Tests cover newest/older windows, active merge, history/backlog ordering, sequence deduplication, expired/gapped cursors, missing scopes, invalid inputs, and internal-metadata non-disclosure.
- OpenAPI and the Go registry define both routes, log DTOs, query bounds, SSE behavior, and `LOG_CURSOR_EXPIRED` consistently.
